This repository will be comprised of articles on ML Algorithms and concepts explaining them from scratch, mathematically and intuitively, looking at them as more of a problem to solve and then figure out the certain concept rather than giving a simple explanation.
I'm doing this because writing a detailed article on something in a way that makes it look like I'm building the concepts from scratch is the best way (for me) to learn ML concepts deeply. 
I hope this repo will help anybody else learning ML, as I was stuck in tutorial hell for a long time without actually understanding anything and I encourage anybody else that's in this situation to read my articles or write articles of their own.
Have fun :)
